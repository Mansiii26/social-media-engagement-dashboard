# Social Media Engagement Dashboard

## Project Overview

This project analyzes YouTube engagement metrics using the YouTube Data API and Python.

The goal is to track content performance using:
- Views
- Likes
- Comments
- Engagement Rate

The project also helps identify top-performing content and improve content strategy.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- YouTube Data API
- Jupyter Notebook
- Power BI

## Features

- Fetch YouTube video data using API
- Analyze engagement metrics
- Calculate engagement rate
- Identify top-performing videos
- Create data visualizations
- Export cleaned data for dashboards

## Metrics Used

- Views
- Likes
- Comments
- Engagement Rate

## Key Insights

- Videos with higher views generated significantly better engagement.
- Some video titles attracted more audience interaction and likes.
- Engagement trends varied across publishing dates.
- Strong correlation was observed between views and likes.

## Recommendations

- Upload videos during high-engagement periods.
- Use attractive titles and thumbnails.
- Maintain consistent content posting.
- Focus on highly engaging content categories.
